# ChariRoute

A map style for OsmAnd, focused on the practice of cycling and cycloTouring in Japan<br>
*(Last update 17/08/2026)*<br><br>

## <img src="icon/info.svg" width="25" > Notable features over standard styles:
<br>

- Inspired by [CyclOSM](https://www.cyclosm.org/) :

     - More legible and visible cycle paths
     - Highlighted useful/interesting POIs
     - Opaque color for routes<br><br>

- Inspired by [Mapy.cz](https://en.mapy.cz/) :
     - Land and Water Color<br><br>

- Japan-specific :
     - The "自転車ナビマーク・ナビライン" (bicycle nav mark / nav line, `cycleway=shared_lane`) road markings, very common on Japanese roads, are highlighted with a dedicated color and dash pattern, distinct from regular cycle tracks and lanes<br><br>

- Additional setting:
     - POI for cycle tourism
     - To hide land use logos<br><br>
- Even more ; )
<br><br>

## <img src="icon/download.svg" width="25" > Installation instructions
<br>

1. Open this repository's [Actions](https://github.com/LogPiyo/osmand-cycloroute-for-JP/actions) tab and pick the latest successful "Producing .osf" run
2. Download the `ChariRoute` artifact (it contains `ChariRoute.osf`)
3. Open the downloaded `.osf` file with the OsmAnd app to import the rendering style
<br><br>
