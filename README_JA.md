# ChariRoute

日本の自転車・サイクルツーリング向けに調整した OsmAnd 用マップスタイルです<br>
*(最終更新日 2026/08/17)*<br><br>

## <img src="icon/info.svg" width="25" > スタイルの特徴:
<br>

- [CyclOSM](https://www.cyclosm.org/) を参考に:

     - 自転車道・自転車専用通行帯をより見やすく強調
     - 役立つ/興味深いPOIを強調表示
     - ルート表示を不透明色に<br><br>

- [Mapy.cz](https://en.mapy.cz/) を参考に:
     - 土地・水域の配色<br><br>

- 日本向けの独自調整:
     - 日本の道路で非常に多く見られる「自転車ナビマーク・ナビライン」(`cycleway=shared_lane`)を、自転車専用道路・専用通行帯とは異なる専用色・線種で強調表示<br><br>

- 追加設定:
     - サイクルツーリング向けPOI
     - 土地利用ロゴの非表示<br><br>
- まだまだ改良中 ; )
<br><br>

## <img src="icon/download.svg" width="25" > インストール手順
<br>

1. このリポジトリの [Actions](https://github.com/LogPiyo/osmand-cycloroute-for-JP/actions) タブを開き、「Producing .osf」の最新の成功したrunを選択
2. アーティファクト `ChariRoute` をダウンロード(中に `ChariRoute.osf` が入っています)
3. ダウンロードした `.osf` ファイルをOsmAndアプリで開き、レンダリングスタイルとしてインポート
